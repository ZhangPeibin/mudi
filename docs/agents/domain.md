# Domain Docs

TokenPlay is a single-context repository.

## Before exploring

- Read root `CONTEXT.md`.
- Read ADRs under `docs/adr/` that affect the work area.
- If either is absent, proceed silently.

## Vocabulary

Use domain terms exactly as defined in `CONTEXT.md`, including Session,
Current Run, Project, Worktree, Current Context, Attention Condition, and
Recent Signal.

Do not replace terms with synonyms that `CONTEXT.md` explicitly avoids.
If a required concept is missing, note it for `$domain-modeling`.

## ADR conflicts

If proposed work contradicts an existing ADR, report the conflict explicitly
instead of silently overriding the decision.
