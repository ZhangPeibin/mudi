领域模型语法速查

阅读 src/domain.rs 时最常见的五个 Rust 结构。

enum：封闭的可能性集合

pub enum Provider {
    ClaudeCode,
    CodexCli,
}

一个 Provider 值只能是列出的变体之一。新增变体后，相关的穷尽 match 通常会由编译器指出需要更新的位置。

impl：给类型定义行为

impl Provider {
    pub fn label(self) -> &'static str { /* ... */ }
}
接收者含义典型用途
self取得值消费值，或复制一个 Copy 小值
&self只读借用读取而不取得所有权
&mut self可变借用原地修改值

match：按形状穷尽处理

match provider {
    Provider::ClaudeCode => "claude",
    Provider::CodexCli => "codex",
}

每个分支都是表达式，整个 match 也产生一个值。这里两个分支都返回 &str。

Option<T>：显式表达“可能没有”

enum Option<T> {
    Some(T),
    None,
}

Option<Provider> 不是空指针：调用者必须处理“有 Provider”和“没有 Provider”这两种情况。

derive：请编译器生成常用实现

Trait在本项目中的作用
Debug允许用调试格式输出值
Clone显式复制完整值
Copy小值赋值和传参时按位复制
PartialEq, Eq允许比较是否相等
Hash允许作为哈希集合或映射的键
Serialize, Deserialize让 Serde 编解码该类型
