# Mission: Learn Rust through TokenPlay

## Why
Learn Rust by reading and changing a real application, with TokenPlay as the concrete
codebase. The goal is to move from recognizing syntax to making reliable changes without
depending on someone else to translate the code first.

## Success looks like
- Explain the ownership, borrowing, enum, struct, `Option`, and `Result` patterns used here.
- Trace session data from provider logs through the domain model to the terminal UI.
- Implement and test a small TokenPlay feature independently.

## Constraints
- Learn in short lessons grounded in the existing code.
- Introduce only the Rust concepts needed for the next practical step.
- Treat the learner as experienced with programming but new to Rust.

## Out of scope
- Compiler internals, unsafe Rust, and advanced macro authoring for now.
